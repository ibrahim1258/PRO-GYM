# PRO GYM Website

موقع ثابت جاهز للرفع على GitHub Pages.

## الملفات المهمة

- `index.html`
- `logo-progym.jpg`
- `hero.mp4`
- `gallery/`
- مساعد داخل الموقع باسم `hady` للرد على الأسعار والمواعيد والحجز والتعليمات.

## النشر على GitHub Pages

1. ارفع كل الملفات في أصل الريبو.
2. افتح `Settings`.
3. ادخل على `Pages`.
4. اختار `Deploy from a branch`.
5. اختار branch `main` و folder `/root`.
6. اضغط `Save`.

بعدها GitHub هيدي رابط الموقع خلال دقيقة أو دقيقتين.
